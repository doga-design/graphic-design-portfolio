# Graphic Design Portfolio

Personal portfolio site for Doğa Cimen.

## Development

```bash
npm install
npm run local
```

## Icons

Site icons are built from [Solar Icons](https://solar-icons.vercel.app/) (Bold Duotone style) into `assets/icons.svg`:

```bash
npm run build:icons
```

- **Solar Icons** by [480 Design](https://solar-icons.vercel.app/) — [CC BY 4.0](https://creativecommons.org/licenses/by/4.0/)
- **Dock GitHub / LinkedIn** — Solar `Command` + custom LinkedIn duotone (`linkedin-duotone-custom.svg`)
- **GitHub / LinkedIn brand** — custom SVGs in `assets/` (mobile nav, case studies)
- **dodoGPT sparkle** — custom asset (`assets/dodollm-sparkle.svg`)
